# Project 2: Data Classification Using AI

**DecodeLabs Artificial Intelligence Internship — Batch 2026**

## Goal
Build a basic classification model using a small dataset.

## Requirements Covered
- ✅ Load and understand a dataset (Iris flower dataset — 150 samples, 4 features, 3 species)
- ✅ Split data into training (80%) and testing (20%) sets
- ✅ Apply a simple classification algorithm (K-Nearest Neighbors)

## How to Run
```bash
pip install pandas scikit-learn
python classifier.py
```

## What It Does
1. Loads the Iris dataset and shows basic info (shape, sample rows, class counts).
2. Splits it into training and testing sets.
3. Trains a K-Nearest Neighbors classifier and evaluates accuracy,
   a classification report, and a confusion matrix on the test set.
4. Bonus: predicts the species of a brand-new, unseen flower sample.

## Skills Demonstrated
Data handling, supervised learning basics, model training.
