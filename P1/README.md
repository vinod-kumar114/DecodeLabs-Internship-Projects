# Project 1: Rule-Based AI Chatbot

**DecodeLabs Artificial Intelligence Internship — Batch 2026**

## Goal
Create a simple rule-based chatbot that responds to predefined user inputs.

## Requirements Covered
- ✅ Handles greetings and exit commands
- ✅ Uses if-else logic for responses
- ✅ Runs in a continuous loop

## How to Run
```bash
python chatbot.py
```

Type things like `hi`, `how are you`, `your name`, `help`, or `bye` to exit.

## Skills Demonstrated
Control flow, decision-making logic, basic AI concepts.
